= Konvario — Documentação

O Konvario é o serviço autônomo da Central IT para manter a
configuração de recursos por tenant. Ele resolve um hostname para um tenant e
entrega, para consumidores autenticados, recursos como banco de dados, storage,
Keycloak e outras configurações operacionais. O serviço também inclui um painel
admin embutido para cadastrar tenants, domains, definitions, resources e API
clients.

Esta documentação segue duas trilhas:
